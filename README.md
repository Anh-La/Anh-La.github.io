# Financial Hub: Understanding Global Financial Architecture

The **Financial Hub** is a research and analytical framework designed to visualize and interact with the complex inter-related influences of the global financial system. This repository/application provides the tools necessary to bridge the gap between abstract macroeconomic theory and practical, entity-level financial management.

## Purpose & Practical Case
Learning traditional financial structures is often hindered by the compartmentalization of data (e.g., personal wealth vs. national policy). This hub provides a unified interface to:

*   **Visualize Systemic Interconnectivity:** Use the *Global Asset Allocation Map* to see how $1,453.2T in global capital is distributed across asset classes like Derivatives, Property, and Crypto, and where these "hubs" of influence reside geographically.
*   **Bridge Micro and Macro:** Understand how personal financial decisions (e.g., ATO tax compliance) interact with broader market structures.
*   **Standardize Financial Literacy:** Move beyond silos by using consistent modeling tools that span from personal portfolios to corporate finance and national-level fiscal simulations.

## Key Components

### 1. The Observatory (Macro Analysis)
The Observatory provides a 2D interactive map and breakdown dashboard. 
*   **Asset Isolation:** Click any marker (e.g., Gold & Metals) or bar to isolate that asset class's global share and hub location.
*   **Data-Driven Insights:** Analyze total global assets and top-performing asset classes through dynamic donut charts and summary stat chips.

### 2. Analytical Tool Suite
The platform aggregates specialized tools into functional categories to facilitate research into financial structures:

| Category | Practical Focus |
| :--- | :--- |
| **Personal Wealth** | Net worth ledgers, ATO tax modeling, and liquidity management. |
| **SMSF Suite** | Statutory compliance audits and contribution caps monitoring for Australian Super Funds. |
| **Corporate Finance** | Financial statement engines, margin metrics, and currency adjustment indicators. |
| **Macro Strategy** | Simulation of fiscal and monetary policy impacts on the nation-state level. |

## Getting Started
1.  **Explore the Hubs:** Navigate the top strip to access specific modules (Personal, Business, Nation State, Global Economy).
2.  **Toggle Context:** Use the language toggle (English/Tiếng Việt) to ensure accurate terminology when researching specific regulatory frameworks like the ATO.
3.  **Perform Simulations:** Select a tool from the "Tools" section to launch a module and begin applying your parameters against active regulatory frameworks.
